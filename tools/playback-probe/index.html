真实视频帧测试 / Playback probe

独立工具，不修改生产 WebView/externalplayer。仅播放您输入且已获授权的 HTTP(S) URL；不会自动遍历或重复请求媒体。

帧指标仅使用 requestVideoFrameCallback 的 presentationTime（提交 compositor，而非物理屏幕显示）。不支持 API 时明确 unsupported，playing/loadeddata 不计为渲染。

每次点击记录一个样本；连续样本请逐次点击。默认 15 秒超时，seek 目标容差 ±0.25 秒。native controls 可辅助观看，但原生拖动不创建测量样本。不要在计时期间用原生 controls seek。
