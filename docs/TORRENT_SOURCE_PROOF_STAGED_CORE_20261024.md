## 核心已实现

- 对原始 info 字节计算 infohash，不重新编码。受限解析器拒绝重复键、非规范整数 / 长度编码、截断、尾随及歧义布局；原字典顺序不要求排序。v2 / hybrid、特殊属性、替代 UTF8 路径字段未支持时拒绝，不套用 v1 假设。
- 采用完整有序清单和零基选中索引，校验与所有选中文件相交的**完整 piece**。包括未选边界和可能跨越的多个小文件，去重交叠 piece；额外读取上限按每个连续选中区间计算，而非全局只多两片。
- 元数据 / 深度 / 节点 / 文件 / piece / 单片 / 总读量 / FD / 路径 / 时间均设预算，预算或邻接不足不输出部分证明。
- 每级目录和叶子拒绝符号链接，叶子只允许精确大小的单链接普通文件，固定 FD 保持至结束；在读前后和最终命名路径重开时检查五元组，检测根替换，错误与取消均关闭 FD。
- 校验 piece SHA1 的**同一遍字节**计算选中文件完整 SHA256，证明绑定元数据、原始 infohash、选择、范围、来源标签、源 SHA / 五元组及所有接触文件。

## 离线验证

夹具为 128 字节、八个 16 字节 piece 及短尾片，覆盖错误字节、共享 / 离散选择、坏 / 缺失邻接、恶意元数据 / 路径、symlink / hardlink / FIFO、短读、变源、超时 / 取消 / 预算。无实际 torrent、生产影片、RPC、网络或运行配置访问。冻结源与测试摘要前后未变。

## 仍必须完成

1. owner / task / expected infohash / 选择由可信持久准入记录验证；非空字符串、证明自摘要不构成认证，未知历史来源不得猜成 direct 来源。
2. 将证明接入持久账本、mover 发布事务、上传前与解码后 SHA 绑定，保护 PUT / 去重 / 切片提交 / 删源全部路径。阶段证明不能单独授权上传或删除。
3. 单链接限制与 mover 硬链接发布尚未衔接；必须明确 pending / committed、link 引起的 ctime 变化和崩溃恢复，不可盲用旧指纹。
4. stat 不是不可变快照。一次中间测试因同一时钟刻度的元数据变化未被识别，夹具改为显式推进 mtime；不得将其宣传为永不变源。后续上传 guard 必须核对完整 SHA256 和身份。
5. 取消 / 截止时间为协作检查，不能打断内核阻塞的普通文件读取；硬墙钟需求需受监督子进程隔离。
