# 定制生产镜像升级兼容性核对

## 结论

当前生产不是单纯的已发布 main 镜像。不能直接用只有容量页面或 WebDAV / 搜索修复的普通新镜像替换，否则会丢失已存在的恢复能力和错误协议。应先将必要兼容补丁放入独立、可审查的提交并通过完整云端矩阵，再构建匹配的服务端及 Web 管理资源，保留固定镜像和一致性数据回滚点。

本报告是只读核对结果，**不是已经部署或全部恢复的报告**。没有执行真实回收站清空。

## 已核实的版本及来源限制

- 已发布基线：`origin/main = 4f1668e25b09435c227c8dab9d2d33561e7839b9`；不能用较旧的本地 main 代替基线。
- 生产标签：`alist-encrypt-go:parentproof-20261020`。
- 生产镜像 ID：`sha256:667dc643322e637414feed77b2df470c0ff31dd3cb5337b91ea6250822444147`。
- 当前容器开启了 Watchtower 允许更新标签；这不证明监视进程正在运行，但后续发布必须防止非受控替换。
- 定制镜像是在旧镜像上复制服务端二进制，不是从带版本标记源码完整重建。二进制含 Go 构建信息但没有 VCS 修订号，镜像继承的旧 main 标签也不能代表实际二进制版本。
- 当前磁盘源码还包含比生产二进制更晚的离线维护和两阶段 complete-loss 工具。不能把整个未提交源码树声称为“生产已经部署的补丁”。

通过只读符号、时间及维护记录交叉核对，可确认生产包含正向读取恢复、受控 failed 释放及结构化写入错误功能；不能据此声称当前源码可逐字节重现历史二进制。

## 普通 main 已有的安全能力

不能误称升级就会丢失所有保护。基线已经具备：

- 加密短文件名及受保护写入长度限制；拒绝受保护断点续传。
- 创建预留前和创建后分别证明远端目标缺失。
- 持久化 pending / failed / complete 预留和 token-CAS 终结，失败预留仍阻止写入。
- 正确大小和当前目录证据的上传成功校验；成功响应缓冲发布。
- 基于当前规则构建的读取索引、验证别名、当前调用者认证及元数据失效机制。

这些是本地数据库保护，不是跨实例分布式写锁或云端通用防覆盖保证。

## 必须保留或独立审查的定制功能

| 功能 | 直接换普通 main 的影响 |
|---|---|
| 管理员正向恢复 failed-but-present 文件 | 丢失显式恢复能力；该恢复仍保留原失败审计及写入围栏，前缀证明不等于整文件完整性 |
| 恢复请求独享的当前调用者 / 新鲜元数据证明 | 丢失防旧下载地址、旧 nonce 和旧几何缓存误用的恢复路径 |
| failed 预留受控维护释放 | 丢失默认 503 禁用的管理维护接口；普通 main 没有该接口仍是失败关闭，不会因此自动解除预留 |
| 完整物理父目录、双 404、最小失败年龄、审计 CAS 归档 | 必须随维护释放一起保留，不能简化为看到一次 404 就释放 |
| `reserved_failed` 等固定写入错误和 503 / 409 区分 | 客户端可能失去准确退避、保留原件和显式恢复诊断契约 |
| 更晚的离线维护 / 两阶段 complete-loss 工具 | 与在线守护程序分开保留和审查，不能无差别复制进发布或声称已在线生效 |

原工作树中尚未提交的维护源码不得被重置、覆盖、临时隐藏或批量混入容量功能提交。

## 数据格式与回滚

恢复、维护归档桶属于增量添加，原文件名主审计及别名结构没有新加密线格式。派生读取索引启动会从主审计重建。旧版本结构上能忽略额外桶，不代表它能识别自定义恢复语义。

维护释放会归档并删除原 claim；complete-loss 会保留 claim 但将其转为新的 failed 状态。只切回旧镜像不能撤销这些语义变化。不得为了回滚删除桶、伪造就绪标记或把旧数据库恢复到后续云写入之上。

应成套保留：固定旧镜像、事务一致数据库备份、运行配置和加密规则、上传交付收据及历史。敏感备份不作为公开附件。

## 发布前顺序

1. 修正旧恢复 PR #102 的认证、缓存隔离及 LP0 几何测试失败，不能仅跳过断言或将失败称为波动。
2. PR #104 的目录大小修复与 PR #105 容量管理分别完成完整矩阵。大小探测仅允许来自原始 DAV 密文长度及保留来源的 DAV 快照，不能让播放 / fs/get / HTTP 快照的明文长度撤销全局确认。
3. 新建隔离兼容集成分支，在当时最新 main 上明确移植必要补丁，处理共享 handler / route 冲突；同一草稿 PR 逐项修正并全绿后才合并。
4. 构建服务端与匹配 Web 管理资源，保留现有上游 OpenList WoPan-UA 镜像及全部驱动；只复制服务端二进制不能交付新的容量界面。
5. 在受控单写者窗口、完整回滚准备和固定镜像下部署；先用数据库恢复副本验证，不让检查进程打开生产数据库触发重建。
6. 现场证明原预留仍阻止覆盖、维护默认禁用、正向恢复认证及缓存围栏、有效 / 无效搜索会话、DAV 大小与重启持久性、容量查询。回收站只打开警告并取消，**不得用真实清空作为测试**。

主线合并、镜像产出、实际替换、现场验收及原有媒体恢复是不同完成条件，不相互代替。
