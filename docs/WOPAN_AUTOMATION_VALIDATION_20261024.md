# 多选容量与自动回收站策略：验证记录

## 范围

仅修改 alist-encrypt-go 隔离工作树与 `agent/cloud-multi-auto-recycle-20261024` 分支。未修改宿主脚本、服务、定时器、容器配置或其他会话。开发及验收未对真实云盘执行 prepare、clear 或 restore；提供方与上游均由模拟对象或 httptest 替代。

新增能力：单选／多选个人盘容量卡；默认关闭、明确危险确认后保存的自动回收站策略。当前仅支持 WoPan 个人账号，不宣称移动、天翼或家庭账号已经接入清理。

## 独立审查发现与修复目标

独立审查用真实处理器路径及模拟提供方复现了两项问题，并保留为 `internal/handler/wopan_automation_review_test.go` 的回归测试：

1. 配置凭据 A→B→A 在两轮之间发生时，旧自动授权可能恢复。修复要求在项目管理接口观察到实际上游配置变化时，原子持久化账号隔离，即使改回原值也需重新确认。
2. 手动清理成功回调可能清除自动校验刚新增的同账号绑定变化隔离。修复要求按账号的新原因围栏、共同互斥，以及持有配置锁时核对运行版本后才清除旧检查点。

同时修复 Windows 不支持目录同步而影响普通配置保存的兼容问题：普通未启用策略的保存保留旧行为，自动策略及检查点严格失败关闭。当前不支持在 Windows 开启本自动清理功能，不以编译成功充当 Windows 运行验收。

最终修复提交、独立复验和全部矩阵结果尚待补记；不得将本记录理解为已合并、已部署或真实自动清理成功。

## 已知边界

- 单应用实例，不提供跨进程分布式租约。
- 已经发给提供方的永久删除无法撤销；关闭仅阻止后续任务并尽力取消。
- 提供方两次查询间未被观察到的外部身份变化，不具备事件追踪保证。
- 持久化保证依赖文件系统同步语义。重命名后的目录同步与磁盘回滚同时失败时，磁盘状态可能未知；当前进程停止自动执行不等于磁盘已恢复，应在重启前停用策略并核对云端结果。
- 不估计回收站占用或可释放容量，不累加同账号多挂载配额。
