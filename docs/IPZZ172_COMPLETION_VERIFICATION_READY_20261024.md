## 门禁与实现

私有工具 `ipzz172_verify_complete_20261024.py`，代码摘要：

`df8ec8ed582ae1a5aab5a2942861dcd9efe2974a46d2efe80c1b640def878234`

工具只在隔离容器自然结束且 `exited / ExitCode 0 / OOM=false` 后允许校验，并在结束时重新核对同一容器、完成时间和镜像。固定候选根、原始种子路径、索引 8、精确镜像 ID、aria2c 入口、选项、bridge / 无发布端口及挂载身份。候选 bind 可写，原始种子 bind 只读；镜像自带的 `/config`、`/downloads` 匿名 volume 可存在，其他挂载拒绝。没有把这些匿名 volume 说成候选旧源。

候选根 metadata walk 上限 4096 项、深度 32，拒绝任何 `.aria2` 控制文件或 symlink；该门禁在读前、读后均执行。所有候选文件与目录用逐层 `dir_fd` / `O_NOFOLLOW` 打开；拒绝非普通文件、hardlink、长度不符，读取后复核 fd 与路径 dev / inode / size / mtime / ctime。旧源只做前后 metadata 比较，不读取或修改其内容；这个字段不等于重新验证旧源内容。

bdecode 限制种子 64 MiB、深度 32、条目 200000、文件 4096，并拒绝重复或乱序字典键、非规范整数、尾随字节、危险路径、piece 数量与长度总量不一致。原始种子读入检查短读和前后身份。

实际载荷校验单遍、每次至多 **64 KiB**：逐个 SHA1 验证所有 984 个完整相交 piece，同一遍计算目标文件完整 SHA256。读取预算由目标几何推导，最长 **300 秒墙钟**，有进程 alarm 与循环期限检查；不申请目标大小的内存，不落临时媒体。失败只输出脱敏错误码，不重试、修改或解除任何保护。
