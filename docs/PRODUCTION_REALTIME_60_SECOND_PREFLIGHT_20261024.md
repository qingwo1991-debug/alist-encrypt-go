# 生产实时 60 秒解码预检（2026-10-24）

## 范围

本轮仅授权 **60 秒实时预检**，没有启动 3600 秒长测。对象为当前持久化完整读回收据匹配的唯一生产对象，明文长度 1,602,702,460 字节。凭据与路径只在私有 helper 进程内存使用，不写入 argv、公开报告或日志。

## 隔离、限额与退出

新建私有 helper，保留此前 30 秒测试脚本和结果不变。临时服务器仅绑定 loopback 随机端口，固定 `/media` 转发唯一对象，严格 Range / 状态 / Content-Length / Content-Range 校验；禁止代理和重定向。媒体调用仅 GET / HEAD，无配置或服务状态变更、无云盘写操作、无回收站接口。

- FFmpeg 5.1.9：`-re` 在输入前，`-short_seek_size 8388608`、`-max_redirects 0`，实际音视频解码到 null，不是 stream copy。
- 输出媒体目标 60 秒；CPU nice 10、线程 2、CPU 时间上限 60 秒、总墙钟上限 120 秒。
- 上游累计读取上限 128 MiB、请求上限 64、上游每次 I/O 至多 5 秒。
- 不给下游写入设 5 秒超时，避免正常实时播放停顿被误判；登记本次所有客户端 socket 和线程，退出时关闭自有 socket 以打断阻塞。
- SIGTERM / SIGINT 转入受控清理：停止读取、终止并回收本次 FFmpeg 进程组、关闭自有 socket、关闭 listener 并 join 线程，写原子 0600 数值结果。
- 每 10 秒记录健康、解码进度和容器内存，根盘必须保留至少 2 GiB；heap >256 MiB 或容器内存 >512 MiB 连续三次则中止；90 秒无进度则中止。

执行媒体前，合成测试创建一个不发送 HTTP 请求头的静默客户端，验证关闭时能解除阻塞；listener 已退出、handler 线程 0、登记客户端 0。该测试未请求生产媒体，不替代所有可能异常路径测试。

## 长测门禁：尚不能直接外推一小时

`-short_seek_size 8MiB` 下本轮仍有 16 个 Range 请求，消费接近 128 MiB 预算。按整片平均码率估算一分钟编码内容约 11.8 MB，但该估算不能替代具体码率、初始化和回读观测；本次读取存在显著读前 / 回读量。**不能按平均码率断言 1 GiB 足够一小时，更不能直接启动 3600 秒。** 需进一步定位 MP4 交错、Range 复用或读取放大，并对资源增长补足证据；若将来触限，必须记录为长测未完成，不自动加大预算。

## 预检后独立源代码审查：长测监督器仍需修正

本次实际正常退出的资源均已清理，数字结果成立；但审查发现不能把同一脚本未经修正直接运行一小时：

- 累积保存每秒 FFmpeg progress stdout 会触及 256 KiB 输出上限，应改有界增量解析，而不是把正常长测误判输出溢出。
- 缺失 heap 字段或无法解析容器内存时原代码使用默认值 / None，不能证明资源限制仍在监测；长测应明确失败关闭。
- 子进程结束与 killpg 间有竞争，异常可能跳过后续代理清理；需独立 finally 保护各清理阶段，并覆盖 listener 停止接受前后新连接的竞争，要求残留客户端也为 0。
- 现有 Range 检查只绑定长度和位置；跨长时读取还需明确对象 validator / identity 一致性证据，不能把完整历史收据当当前每段永不变化的证明。

这些是本次正常预检之外发现的潜在边界，不冒称已在现场触发。修正与合成回归进行中；未执行一小时测试，也不因一分钟通过而放宽预算。

## 解释边界

即使预检通过，也只证明该对象在这一次服务状态下可以实时解码约一分钟；不代替 60 分钟持续播放、物理播放器体验、冷态、直链过期、扫描争用或全文件解码验证。输入读取量是转发器消费的明文字节，不等于 CDN 线路流量或服务器预读量。容器内存统计不严格等同于进程 RSS。
