# 历史恢复副本审计字节保留核对（2026-10-24）

## 新增工具与验证

`tools/backup-audit` 是只依赖标准库和 bbolt 的离线只读程序，不初始化服务 / 存储构造器、不创建桶、不修复、不发送网络请求。仅对显式私有副本根目录下的现有文件操作，拒绝已知生产路径、越界符号链接及硬链接，打开锁超时 1 秒。输出固定白名单桶的计数和有序键值摘要；用户 / 规则 / 配置只计数，不输出键值或其摘要。

本地默认模块缓存缺依赖的首次测试超时后，没有继续下载或重型重试；改用仓库既有 `.gopath` 缓存并禁用网络，普通测试通过（0.963 秒）、race 测试通过（2.002 秒）。五组测试使用临时合成 Bolt，涵盖未知 / 无效状态不能计为完成、数据不变、摘要变化、脱敏、路径和锁限制、取消、0600 独占报告。

## 演练输入与实际结果

输入 A 为既有 2026-10-20 历史数据库的全新私有文件副本；输入 B 为此前完全断网执行 **新镜像→旧 parentproof 镜像→新镜像** 启动后的历史恢复副本。两个演练容器均正常退出后才打开 B，从未打开生产 Bolt。

| 白名单数据 | 升级前历史副本 | 演练后副本 | 对照 |
| --- | --- | --- | --- |
| filename reservations | 56 条：complete 39、failed 17、pending 0、unknown 0、invalid 0 | 相同 | 有序键值 SHA256 完全一致 |
| recovery 审计 | 桶不存在 | 桶不存在 | 相同，不冒称测试了非空恢复审计 |
| retry 审计 | 桶不存在 | 桶不存在 | 相同 |
| verified alias / reverse | 桶不存在 | 桶不存在 | 相同 |
| users | 1 | 1 | 仅计数 |

预留桶摘要：`643f2e70407ac2f50fd8989dec4baf74275b7b9df518cac45c0adc71698302c7`。摘要比较包含完整原始键值字节，而不是仅凭条目数量判断没有丢失。派生索引及缓存、事务号和数据库大小不要求相同，不能用它们代替审计桶比较。

## 不可越过的边界

- `inventory_only=true`，`snapshot_consistency_validated=false`。工具不是结构、逆索引、审计语义或完整数据库校验器。
- 历史备份本身没有本次当前事务一致性证明；此结果不能称当前备份、当前完整迁移或生产回滚已验证。
- 当前恢复审计可能比历史副本更新，仍需等待上传安全空窗后，对最新成套一致性副本重新验证。
- 不证明云文件存在、内容正确、上传成功或真机播放；没有释放任何预留，也没有恢复 / 覆盖 / 删除云对象。
