# Docker 本地 WebDAV 大小与 Ctrl+K 搜索修复

## 2026-10-24 现场诊断（修复前）

本报告只记录去凭据化结果，不包含配置、登录令牌、签名下载地址或完整云盘清单。

### WebDAV 文件大小

同一目录、同一显式调用者凭据，执行只读 `Depth: 1 PROPFIND`：

| 端点 | HTTP | 目录 / 文件 | 成功的文件大小属性 | 大小属性不可用 |
|---|---:|---:|---:|---:|
| 上游 `:5244` | 207 | 1 / 1820 | 1820 | 0 |
| Docker 本地代理 `:5344` | 207 | 1 / 1820 | 0 | 1820 |

上游约 0.319 秒，本地代理约 4.062 秒；这不是客户端显示问题。代理不能把密文长度直接当作明文大小：V1、V2、V3 容器开销不同。旧代码在缺少容器确认记录时返回 WebDAV 大小属性 404，但 `trusted_local` 同时禁止所有普通列表后台探测。现场已提交 Bolt 页面中，确认几何桶和 fileinfo 桶均为空，形成“没播放就一直没大小”的死循环。

另外，已确认几何查询错误地要求先找到普通 raw-path 镜像；重启或缓存淘汰后，即使持久化确认记录有效，也可能无法显示。目录快照还会长期保留先前的 `size=-1`，不会随确认完成更新。

只读单文件 `Depth: 0` 验证成功：一个原本目录大小缺失的样本，在约 0.564 秒内返回 HTTP 207、正确可用的明文大小，证明实际对象的轻量容器确认可行。该验证不等于全文件完整性或播放正确性证明。

### Ctrl+K 搜索与重登录

使用同一个有效的上游登录令牌，保存在测试进程内存，不打印、不写盘：

| 请求 | 上游 | 本地代理 |
|---|---|---|
| `/api/me` | HTTP 200 / code 200 | HTTP 200 / code 200 |
| `/api/fs/list`，根目录 | HTTP 200 / code 200 | HTTP 200 / code 200 |
| `/api/fs/search`，同一搜索请求 | HTTP 200 / code 200 | HTTP 200 / code 401 |

本地搜索错误正文为 `Guest user is disabled, login please`。文件浏览器收到 JSON `code:401` 后跳转登录页。现场没有证据表明账号被删除；用户描述的“鬼魂账户”实际复现为访客账户提示。无效上游令牌直接访问上游会保留 `token is invalidated`，经过旧搜索代理却被改成访客错误，进一步证实凭据丢失。

根因是搜索专用 `proxyToAlist` 删除了调用者的 `Authorization`；普通目录列表使用另一条保留该头的链路，因此出现“列表能打开，搜索让重新登录”。管理界面的 `Authorizetoken` 是另一套本地 JWT，不应替代上游会话。

## 修复边界

1. 搜索保留显式上游 `Authorization` 和 Cookie，继续剥离本地管理 `Authorizetoken` / `X-User-Token`；不注入扫描管理员凭据，不开启访客，不吞掉真实 401/403。
2. 目录大小优先查询当前 origin / raw path / 加密规则绑定的持久化几何确认，不依赖普通 raw-path 镜像。必须具备完整容器几何并与本次密文长度严格相符。
3. trusted-local 的目录工作只允许受限的后台 **size-only** 确认，复用有界队列、提供商并发和前台暂停；不恢复旧的大范围预热、解码或 KDF 工作。使用当前显式凭据，捕获配置版本及失效代次；变更后不可发布旧结果。
4. V1/V2 只需有界前缀；V3 按格式读取头部及必要的大小尾部。该过程确认大小，不是全文件认证或媒体修复。首个全冷目录可能暂缺部分大小，后台确认后刷新可出现；不在目录请求里串行探测 1820 个文件。
5. 快照保留原始观察到的密文长度与 raw path，每次响应重新叠加当前确认大小；旧快照缺乏长度来源时回源一次，不把负数、明文或密文长度混用。新确认无需等待旧快照超时才显示，失效后也不能继续显示旧大小。

## 与既有任务的关系

本轮使用基于已发布 main 的隔离工作树，避免混入原目录中未提交的上传失败重试 / 离线维护工作。已有 SNOS-229 安全恢复 PR、坏媒体重下载及播放性能验收保持独立，不能因本轮修复而宣布它们完成。当前现场镜像是自定义 `parentproof-20261020`，不是新的本轮发布镜像；替换前必须保留镜像及数据回滚点并核对自定义安全措施，不能静默丢弃。
