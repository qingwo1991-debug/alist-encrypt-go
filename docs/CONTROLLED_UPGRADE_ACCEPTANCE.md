## 只读现场验收

### 原有保护

- 对恢复副本运行 claim / 恢复读取测试；现场不制造上传失败、不释放真实 claim、不删除云对象。
- 证明已有 failed / complete 记录的写入防覆盖契约保留，结构化错误不被替换为普通成功或可自动重试提示。
- 正向读取恢复仍需要明确授权及当前调用者证据，前缀证明不等于整文件完整性。
- 维护默认禁用；无法建立正确命名空间和无虚拟回退的物理父目录证明时也必须拒绝释放。

### 搜索和 DAV

- 复用同一有效上游会话执行 Ctrl+K 搜索；保留用户 Authorization，不借扫描管理员账号。
- 无效会话不变成匿名 guest，不意外清掉本地管理 JWT；不把未授权错误冒充“没有结果”。
- 同对象比较原始上游密文长度和代理明文长度，覆盖目录有 / 无尾斜杠、Depth:0 / 1、HEAD 及 Range。
- 冷目录承认部分长度暂不可用；有界队列逐步收敛，不把一次 1820 项目录刷新承诺为全部瞬时确认。
- 证实成功 GET、邻集预热、fs/get、普通 HTTP 快照不清除其他已确认大小；必要时先在恢复副本验证。
- 检查 V1/V2/V3 及空 V3 协议回归；真现场只有某一格式时如实标注，不能编造其他格式实测。

### 容量和确认界面

- 未登录的 GET 容量 / 存储接口拒绝，当前有效本地管理员可正常进入页面。
- 只查询选定个人 WoPan 账号，显示总量、已用、剩余和查询时间，回收站大小明确未知。
- 页面、响应和日志不出现 access / refresh token、账号标识或上游凭据。
- 仅打开回收站警告并取消。**不发送真实 clear 请求，不靠“现在应该是空的”来测试。**
- 模拟传输中覆盖一次性凭证、过期、重放、配置切换、并发及未知结果；生产不通过重复清空证明这些场景。
