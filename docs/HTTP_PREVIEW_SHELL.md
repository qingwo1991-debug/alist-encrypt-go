# HTTP 文件列表：立即显示视频预览占位

## 问题与范围

5344 端口代理的 OpenList 前端在 `/api/fs/get` 返回后才切换到 File 状态并懒加载播放器。加密代理可能在 JSON 响应前同步探测冷文件头；V3 还可能需要补充头或尾信息。不能靠跳过探测、提前伪造明文大小来显示播放器。

本修复由 alist-encrypt-go 提供固定的同源 JS/CSS 增强，不修改 Vue 管理后台，不替换上游散列 bundle，不 fork 上游前端。它解决的是**用户导航后到播放器区域出现的等待反馈**，不声称缩短视频首帧、网络取链或解密耗时，也不声称已经测得现场约一秒的分段组成。

## 行为

- 识别到 OpenList 主应用文档后，注入 `/__aeg/preview-shell/v1.js` 和 `v1.css`。
- 普通视频链接点击，或 OpenList 路由导航至视频扩展名路径时，同步展示 16:9 加载占位。路由观察覆盖列表、网格、键盘及双击打开方式，不依赖上游文件名散列。
- 占位位于 `.obj-box` 之前的独立节点，不隐藏、改写或搬动上游应用节点；不会阻挡播放器挂载。
- 新播放器可见后交接；离开目标页面、按 Escape、点击关闭、页面卸载或十秒兜底超时均清理。
- 不包装 fetch/XHR，不读请求/响应体、存储、Cookie 或令牌，不增加媒体/API请求，不设置媒体地址、大小、预加载或自动播放。
- 不改变后端鉴权、加密几何、明文大小、Range 或探测校验。文件详情失败时上游原页面仍保持可见，占位可关闭且有界超时。

## 保守兼容边界

- 只增强通过结构识别的 OpenList HTML：doctype、head/body、唯一 root、OpenList 配置/动态基址 bootstrap 及 module 入口特征。未知版本或主题特征不符时不增强。
- 下载/API/WebDAV/管理路径、附件、部分响应、非 HTML、未知字符编码、`no-transform`、`base`、显式 CSP（包含 report-only/meta）均不注入；不放松 CSP。
- 浏览器 HTML 文档导航向上游请求 identity 编码并移除条件校验头，以免旧 304 文档跳过注入。API、媒体及静态资源不采取该请求策略。
- 透传压缩或不可变换的响应，不把压缩字节当文本；实际改写正文后去掉失效的长度、ETag、Last-Modified 和完整性摘要。未改写正文保留校验头。
- 本地静态资源只返回嵌入固定字节，支持 GET/HEAD，其余方法 405，nosniff，不读取配置或反射凭据。
- 未支持的扩展名、显式 CSP 部署、上游 DOM 大幅变化均退回原行为。此层不强制预取播放器脚本，不会提前请求未经授权的媒体。

## 验证

本轮本地使用现有离线依赖缓存：

- Go 聚焦测试覆盖 HTML 正例/拒绝矩阵、幂等、固定资源、代理响应、压缩透传、缓存/完整性响应头，以及既有冷探测、暖元数据复用、正确明文大小。
- `enc-webui/src/utils/http-preview-shell.test.js` 直接读取实际嵌入 JS，以 jsdom 覆盖即时显示、隐藏/旧播放器、容器替换、快速导航、历史导航、取消/超时、零额外网络和安装幂等。该文件借用现有 Web CI 测试设施，不代表修改管理页面行为。
- 新增测试 ESLint 和 `git diff --check` 通过。

真实浏览器未验收：本环境没有 Chrome，未安装浏览器，未操作私有视频或生产服务。DOM 模拟不证明真实浏览器绘制时刻、页面主题布局或物理设备首帧；`device_unverified` 保留。合并与 CI 不等于部署生效，服务部署须独立安排。
