# 联通云盘容量与回收站管理

## 功能范围

管理入口为加密代理的管理后台 `/public/index.html#/tools/cloud-storage`，不是公开文件列表，也不是普通 WebDAV 用户权限。

- 读取当前配置 OpenList 中的 WoPan 挂载，显示个人账号总量、已用、剩余及查询时间。
- 容量是**个人账号整体容量**，不是挂载目录或加密目录的配额。底层文件容器开销等也由云端计量；该数值不等同本地明文文件大小之和。
- 不支持的家庭盘、不可用存储或授权失败必须明确报错，不用个人盘容量替代家庭盘，也不把未知显示成零。
- 云端没有提供已验证的回收站列表或占用量；显示“未知”，不推测可释放空间。
- 支持发起个人账号回收站清空请求，但**开发及现场验收不得实际清空用户回收站**。真实清理由用户在界面明确确认后自行发起。

## 已验证的接口与现场读取

目标 OpenList 为 v4.2.7，WoPan SDK v0.1.5。现有驱动的 `GetDetails` 调用 `QueryCloudUsageInfo`。生产的容量隐藏设置开启，因此不能以管理存储列表没有 `mount_details` 推断容量为零，也不应静默修改全局隐藏设置。

2026-10-24 的只读账号查询曾返回：

| 字段 | 字节 |
|---|---:|
| 总容量 | 8,796,093,022,208 |
| 已用 | 5,948,854,898,566 |
| 剩余 | 2,847,238,123,642 |

即总量 8 TiB、剩余约 2.59 TiB。该表是带时间的历史读取，不是界面的实时数据；后续使用可能变化。回收站占用量未知。没有调用真实清空接口。

公开协议参考：[WoPan SDK v0.1.5](https://github.com/OpenListTeam/wopan-sdk-go/tree/v0.1.5)、[个人盘接口](https://github.com/OpenListTeam/wopan-sdk-go/blob/v0.1.5/docs/personal-fs.md)。`EmptyRecycleData` 的参数仅为客户端标识，没有目录、文件、家庭或挂载标识；因此只能将其解释为**个人账号整个回收站**的不可恢复清理，不能声称仅清理当前挂载或 `encrypt` 文件夹。

## 其他运营商容量接口

现有 OpenList 驱动还具备以下容量读取能力，但“驱动有接口”不等于本轮 WoPan 管理页面已接入它们：

| 云盘 | 驱动及接口 | 空间范围与条件 |
|---|---|---|
| 中国移动云盘 / 和彩云 | `139Yun.GetDetails`；`getPersonalDiskInfo` / `getFamilyDiskInfo` | 支持个人、家庭；需要 `user_domain_id`，为空时驱动明确返回不支持，不能显示零容量 |
| 天翼云盘 | `Cloud189.GetDetails`；`getUserSizeInfo.action` | 该驱动的容量结果取个人盘字段 |
| 天翼云盘 PC / TV | `Cloud189PC.GetDetails` / `Cloud189TV.GetDetails`；`getUserSizeInfo.action` | 按挂载类型选择个人或家庭容量，不能混用 |
| 联通沃盘 | `WoPan.GetDetails`；`QueryCloudUsageInfo` | 已验证个人账号总容量；家庭盘容量语义未确认，当前失败关闭 |

三家均可在正确授权及配置前提下取得容量。统一展示时应标明提供商、账号/家庭空间、总量、已用、剩余、查询时间和错误状态；相同账号多挂载不能重复加总。容量接口的存在**不代表**具有同范围回收站清空接口或权限。

版本差异：上表的移动个人/家庭分支来自仓库内移动端捆绑驱动；当前 Docker 的 OpenList v4.2.7 使用另一版移动驱动，其 `GetDetails` 调用统一的 `/user/disk/quota/detail`，没有该个人/家庭分支，同样要求 `user_domain_id`。现场 3 个移动挂载均缺少该字段，不能声称已取得真实容量或已验证家庭范围。天翼的 2 个 `189CloudPC` 挂载分别为个人、家庭，驱动具有对应容量字段选择；本轮未查询它们的真实配额。当前 WoPan 页面不包含移动、天翼的展示，后续可独立扩展，不能混淆“可接入”和“已接入”。

## 授权及安全边界

1. 新入口只注册在本地管理 JWT 保护的 `/enc-api/wopan/*` 下，核对当前真实管理用户；不能仅信任前端的 `roles` 标签。
2. 上游会话来自当前配置的扫描/管理凭据，另行验证 OpenList 管理员身份。普通扫描账号不能获得账号级清空权限。本地管理 JWT 与 OpenList 令牌不可互换，不能将本地 JWT 发送给上游。
3. 上游目标只能取当前配置，提供商目标固定为官方 HTTPS 地址；浏览器不能提交任意 URL、账号令牌或存储 `addition`。禁止自动跟随重定向、自动刷新账号令牌和自动重试清空请求。
4. 浏览器只收到去凭据化存储信息和容量字符串。存储配置、访问/刷新令牌、账号标识、错误原文均不得返回、记入公开日志或写入前端资源。
5. 清空采用两步确认：先获取短期随机凭证，再输入“清空个人账号全部回收站”。凭证绑定本地管理会话、当前配置、存储和账号，只能使用一次。
6. 执行前重新确认挂载为可用个人盘且账号、配置没有改变。先消费凭证，再发送清空请求；并发请求及重放不得重复触发操作。检查 JSON 请求体、Origin / Fetch Metadata，拒绝跨站及未知字段。
7. 成功仅表示云端接受请求，不承诺立刻为空、释放多少空间或回收站是否计入配额。网络超时后的结果可能未知，不能自动重复提交，应由用户先在官方客户端确认。

## 管理 API 契约

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/enc-api/wopan/storages` | 可选 WoPan 存储及个人/家庭范围、支持状态 |
| GET | `/enc-api/wopan/quota?storage_id=N` | 查询明确选中个人账号容量 |
| POST | `/enc-api/wopan/recycle/prepare` | 准备账号级清空确认凭证，不清空 |
| POST | `/enc-api/wopan/recycle/clear` | 校验并消费凭证后发起不可逆请求 |

容量字节使用十进制字符串，避免浏览器大整数精度丢失；回收站字节为 `null`。准备及执行只接受 JSON，执行要求存储 ID、随机确认凭证和精确确认文字。错误为固定、去凭据化说明。

## 验证与发布要求

本功能使用独立 `agent/*` 分支，保留上传恢复及 WebDAV / 搜索修复的隔离工作树，按格式检查、针对性测试、Draft PR 全矩阵验证推进。测试中的清空全部使用模拟 HTTP 传输，**禁止针对真实账号测试清空，即使声称回收站为空**。

现场验收只允许：

- 未登录访问应拒绝；非管理员上游会话应拒绝。
- 显示当前真实个人账号容量、时间、范围及未知回收站大小。
- 打开清空确认界面、核对警告并取消；不得点击最终清空或自动提交。
- 对比当前官方容量，确认页面刷新及错误状态；核查返回内容与静态资源无凭据。
- 保留原生产自定义镜像及数据回滚点，核对既有上传围栏、维护释放默认关闭和安全恢复措施后，才可替换生产镜像。

**实现、CI、正式部署和现场验收是不同阶段。本文的接口约定及历史只读容量，不构成已部署或真实清空成功的声明。**
